[Effekseer 샘플 프로젝트 추출 방법]
(당신의 컴퓨터 C드라이브 내에 CMake가 다운받아져 있다는 가정을 전제로 한다.)

샘플 프로젝트 추출하는 이유 - 샘플 프로젝트 코드 보고 공부하여 내 프로젝트에 적용시키기 위함

1. Effekseer 공식 홈페이지에서 Download -> Effekseer for C++ 에서 최신버전 다운

2. 당신의 컴퓨터 C드라이브에 새폴더 만들기 (이름 예시: EffekseerCpp170e)

3. 만든 폴더 안에 1번에서 받은 압축파일 압축 풀기

4. Visual Studio 2022 실행 -> 로컬 폴더 열기 -> 만든 폴더 선택 (예시: EffekseerCpp170e)

5. (Visual Studio 내에서) 프로젝트 -> 캐시 구성 클릭

6. (Visual Studio 내에서) 빌드 -> 모두 빌드 클릭
※ 여기까지 했을때, 오류가 나는게 정상임 (오류: '/wd"4100"' 어쩌구)

7. (Visual Studio 내에서) 편집 -> 찾기 및 바꾸기 -> 파일에서 찾기 -> 찾기(N)란에 "4100" 입력
-> 찾는 위치를 EffekseerCpp170e 폴더로 선택 -> 모두 찾기 클릭

8. 찾기 결과란에 4개의 결과가 뜸 -> 하나씩 더블클릭 -> 이동 -> "4100" 부분을 4100 으로 변경 " "제거

9. 4개 부분 모두 4100으로 변경 후 ctrl + shift + s (전체 저장)

10. 프로젝트 -> 캐시 삭제 및 다시 구성 클릭 
(이후 C드라이브 -> EffekseerCpp170e -> out -> build -> x64-Debug -> 여러 폴더 및 파일들 생성 된거 확인)

11. 키보드 윈도우 키 -> Developer Command Prompt for VS 2022 혹은 cmd 실행

12. cd C:\EffekseerCpp170e 입력

13. rmdir /s out\build\x64-Debug 입력 -> 계속하시겠습니까(Y/N) 질문에 Y 입력 후 엔터

14. cmake -B out/build/x64-Debug -DCMAKE_BUILD_TYPE=Debug -DCMAKE_MSVC_RUNTIME_LIBRARY=MultiThreadedDebugDLL -DCMAKE_POLICY_VERSION_MINIMUM=3.5 입력
※ 주의, 당신이 미리 다운해놓은 CMAKE 버전을 3.5 대신 입력 !!

15. cmake --build out/build/x64-Debug --config Debug 입력

16. 성공적으로 Command Prompt가 작업 완료하면, C드라이브 -> EffekseerCpp170e -> out -> build -> x64-Debug 내에 Effekseer.sln 프로젝트 생성됨
