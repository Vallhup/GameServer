*Ville Tamminen, “Combat hit detection system for 3D action role-playing games in Unity” (Bachelor’s Thesis, 2022)

논문 개요
 - Unity Engine 기반 3D Action RPG에서 사용할 수 있는 정확한 전투 판정 시스템 구현
 - Dark souls과 같은 다수의 작은 본 단위 Colider를 활용한 정밀한 판정 시스템

구현
 1. Solution 1
  - 단일 Hurtbox -> 다중 Hurtbox -> 고급 다중 Hurbox 순 확장
  - 공격 무기에는 Hitbox, 피격 대상에는 Hurtbox 추가
  - 별도의 충돌 판정 Info 구조체로 판정 관리

 2. Solution 2
  - 충돌 처리 기능을 무기 코드로 통합
  - 공격/애니메이션 시간에 의존하지 않고, 공격 시작 시 Hit 기록을 초기화 + 피격 List 추가하는 방식


현재 구현 방식
 - 해당 논문의 Solution 2에 좀 더 가까운 구조

 - 우리 게임은 무기 스왑이 없으므로 Solution 1의 기본적인 다중 Hurtbox 구조는 유지
   but 과도한 animation_frame_time + attak_id 관리 구조는 오버엔지니어링

 - Client의 Input 요청은 서버에서 처리되어 Character는 특정 State에 진입하게 되고 해당 State Class에서
   관련된 모든 처리를 전담(현재는 회피 시 강제 이동 처리 중)

 - Solution 2의 충돌 처리 방식을 채택하면 현재 코드의 Attack State에서 피격 List를 관리해서 중복 충돌 방지
   + 충돌 검사 루프에서 Hitbox vs Hurtbox 검사 하는 방식으로 구현할 수 있음


추가적인 최적화 방법
 - 이벤트 기반 동기화 : Action Event가 실행되는 동안에 그에 맞는 frame_time에만 Colider를 활성/비활성화 시켜
   불필요한 충돌 검사 최적화

 - 프리컴퓨팅(Precomputed Collider Track) : 매 프레임마다 서버에서 본 행렬을 계산하는 것이 아니라 애니메이션 별로
   Bone-Colider Track을 미리 베이킹 시켜놓고 런타임에는 애니메이션 진행 시간만 관리하면서 Colider Position Update
