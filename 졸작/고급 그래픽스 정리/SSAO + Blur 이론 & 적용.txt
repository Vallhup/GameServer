//------------------------------------------------------------
// Screen Space Ambient Occlusion (SSAO) 개요
//------------------------------------------------------------

물체의 틈새나 모서리에서 자연스러운 주변광 차폐를 표현하기 위한 기법
실시간 렌더링에서 Global Illumination의 근사치를 제공
스크린 공간에서 계산되어 씬 복잡도와 무관하게 일정한 성능 유지


//------------------------------------------------------------
// SSAO 핵심 아이디어
//------------------------------------------------------------

각 픽셀 주변의 반구 영역에서 무작위 샘플링을 수행하고,
샘플 위치의 깊이가 현재 픽셀보다 앞에 있으면 차폐된 것으로 판단

필요한 입력 데이터 :
- View Space Normal(G - Buffer에서 획득)
- Depth Buffer(깊이 정보)
- Noise Texture(샘플 회전용)
- Sample Kernel(반구 영역의 샘플 포인트들)

기본 흐름 :
1. 현재 픽셀의 뷰 공간 좌표 복원(Depth → View Position)
2. 노이즈 텍스처로 무작위 TBN 행렬 생성
3. 샘플 커널을 TBN으로 회전시켜 반구 방향 정렬
4. 각 샘플 위치의 깊이와 비교하여 차폐 여부 판단
5. 차폐 비율을 최종 AO 값으로 출력


//------------------------------------------------------------
// 샘플 커널 생성 (Sample Kernel Generation)
//------------------------------------------------------------

반구 내의 무작위 샘플 포인트를 미리 계산하여 상수 버퍼로 전달

샘플 분포 특징 :
- XY 범위 : [-1, 1] (반구의 수평 방향)
- Z 범위 : [0, 1] (반구의 수직 방향, 표면 위쪽만)
- 정규화 후 스케일링하여 단위 반구 내에 분포

원점 집중 가중치(Accelerating Interpolation) :
표면 가까이에 더 많은 샘플을 집중시켜 정밀도 향상
scale = 0.1 + (i / sampleCount)² × 0.9
→ 0.1에서 시작해 1.0까지 이차함수로 증가


//------------------------------------------------------------
// 노이즈 텍스처 (Noise Texture)
//------------------------------------------------------------

샘플 커널을 픽셀마다 다른 방향으로 회전시켜 밴딩 아티팩트 방지

텍스처 사양 :
- 크기 : 4×4 픽셀(매우 작음, 타일링으로 반복 사용)
- 포맷 : R32G32B32A32_FLOAT
- 내용 : XY 채널에[-1, 1] 범위의 무작위 벡터 저장

TBN 행렬 생성 과정 :
1. 노이즈에서 무작위 벡터(randomVec) 샘플링
2. Tangent = randomVec - Normal × dot(randomVec, Normal) (그람 - 슈미트)
3. Bitangent = cross(Normal, Tangent)
4. TBN = [Tangent, Bitangent, Normal]


//------------------------------------------------------------
// SSAO 아티팩트 및 해결책
//------------------------------------------------------------

Self - Occlusion(자기 차폐) :
표면이 자기 자신을 차폐하는 것으로 잘못 판단하는 현상
해결 : Bias 값 추가(sampleViewPos.z >= sample.z + bias)

Halo Artifact(후광 현상) :
멀리 있는 물체가 가까운 물체를 차폐하는 것으로 판단되는 현상
해결 : Range Check(거리 기반 감쇠)
rangeCheck = smoothstep(0.0, 1.0, radius / |fragPos.z - samplePos.z | )

Banding(줄무늬 현상) :
샘플 수가 적을 때 규칙적인 패턴이 보이는 현상
해결 : 노이즈 텍스처로 샘플 방향 무작위화 + Blur 후처리


//------------------------------------------------------------
// SSAO Blur (Bilateral Blur)
//------------------------------------------------------------

SSAO 결과의 노이즈를 제거하면서 엣지를 보존하는 블러 처리

구현 방식 :
- 5×5 박스 필터(25개 샘플 평균)
- 1 / 2 해상도에서 처리하여 성능 최적화

Edge - Aware 옵션(미적용 시) :
단순 박스 필터는 물체 경계에서 AO가 번지는 문제 발생
개선 : 깊이 / 노말 차이를 가중치로 사용하는 Bilateral Filter


//------------------------------------------------------------
// 메모리 구조 및 성능 최적화
//------------------------------------------------------------

렌더 타겟 :
-SSAO RT : R8_UNORM, 1 / 2 해상도
-SSAO Blur RT : R8_UNORM, 1 / 2 해상도

SRV 힙 구성 :
- Index 0 : Normal(G - Buffer RT1)
- Index 1 : Depth Buffer
- Index 2 : Noise Texture
- Index 3 : SSAO Result(Blur 입력용)

상수 버퍼 구조 :
- samples[16] : 샘플 커널(64 bytes)
- noiseScale : 노이즈 타일링 스케일(8 bytes)
- samplingRadius : 샘플링 반경(4 bytes)


//------------------------------------------------------------
// SSAO를 위한 세팅 변경사항
//------------------------------------------------------------

[SSAO 클래스 구조]
- SSAO RT / SSAO Blur RT 생성(1 / 2 해상도, R8_UNORM)
- RTV Heap 생성(2개: SSAO, Blur)
- SRV Heap 생성(4개: Normal, Depth, Noise, SSAO Result)
- Sample Kernel 생성(16개 샘플, 이차함수 가중치)
- Noise Texture 생성(4×4, Upload Buffer → Default Heap)
- SSAO Constant Buffer 생성

[PSO 추가]
- PSOType::Ssao(SSAO 계산용)
- PSOType::SsaoBlur(블러 처리용)

[Root Signature 추가]
- Slot 17: SsaoCB(b8)
- Slot 18 : SSAO SRV Descriptor Table(space4)
