//-------------------------------------------------------------------------------------------------
// 1. 왜 Ray Marching인가 ?
//-------------------------------------------------------------------------------------------------

일반 렌더링 vs 볼륨 렌더링

일반 렌더링 (표면):
- 광선이 물체 표면에 닿으면 -> 색상 반환
- 계산 1번으로 끝

볼륨 렌더링 (안개, 연기, 구름):
- 광선이 "공간"을 통과함
- 공간 안에서 빛이 흡수되고 산란됨
- 연속적인 계산 필요 -> Ray Marching 사용


//-------------------------------------------------------------------------------------------------
// 2. 빛이 안개를 통과할 때 일어나는 일
//-------------------------------------------------------------------------------------------------

[광원] ~~~~~> [안개 입자] ~~~~~> [카메라]
		  ↓
	      3가지 현상 발생

현상 1: Absorption (흡수)

빛이 안개 입자에 흡수되어 사라짐
-> 안개가 짙을수록 뒤가 안보임

현상 2: Out-Scattering (외부 산란)

빛이 입자에 부딪혀 다른 방향으로 튕겨나감
-> 원래 방향의 빛이 줄어듦

현상 3: In-Scattering (내부 산란)

다른 방향에서 온 빛이 입자에 부딪혀 카메라 방향으로 들어옴
-> 안개 자체가 밝게 보이는 이유 (Light Shaft의 원리)


//-------------------------------------------------------------------------------------------------
// 3. Beer-Lambert 법칙
//-------------------------------------------------------------------------------------------------

빛이 매질을 통과할 때 얼마나 살아남는지 계산하는 공식

수식
T = e^(-τ)

T = Transmittance (투과율, 0~1)
τ = Optical Depth (광학적 깊이)
e = 자연상수 (2.71828...)

τ = Optical Depth (광학적 깊이)
τ = σ × d

σ = Extinction Coefficient (소멸 계수 = 흡수 + 산란)
d = 이동 거리

직관적 이해 예시
τ = 0 -> T = e^0 = 1.0		-> 빛 100% 통과 (안개 없음)
τ = 1 -> T = e^-1 = 1 / e ≈ 0.37	-> 빛 37% 통과
τ = 2 -> T = e^-2 = 1 / e^2 ≈ 0.14	-> 빛 14% 통과
τ = 5 -> T = e^-5 = 1 / e^5 ≈ 0.01	-> 빛 1% 통과 (거의 불투명)

왜 지수함수를 채택하는가?
안개를 10m 통과 	-> 빛이 50% 남음
또 10m 통과	-> 남은 빛의 50% = 전체의 25%
또 10m 통과	-> 남은 빛의 50% = 전체의 12.5%

-> 거리에 따라 지수적으로 감소하기 때문에 지수함수 채택


//-------------------------------------------------------------------------------------------------
// 4. 전체 렌더링 방정식
//-------------------------------------------------------------------------------------------------

최종 색상 = 배경 색상 x 투과율 + 산란된 빛
L = L_background x T + L_inscattering

L_background:	물체의 원래 색상 (Lighting Pass 결과)
T:		투과율 (안개를 통과하고 남은 빛의 비율)
L_inscattering:	안개가 빛을 받아 카메라로 보내는 빛

예시
배경 = 빨간 벽 (1, 0, 0)
투과율 = 0.3 (안개가 꽤 짙음)
산란 = 회색 빛 (0.5, 0.5, 0.5)

최종 = (1, 0, 0) x 0.3 + (0.5, 0.5, 0.5)
= (0.3, 0, 0) + (0.5, 0.5, 0.5)
= (0.8, 0.5, 0.5) <- 빨간 벽이 회색 안개에 가려진 색


//-------------------------------------------------------------------------------------------------
// 5. Phase Function (위상 함수)
//-------------------------------------------------------------------------------------------------

빛이 입자에 부딪혔을 때 어느 방향으로 산란되는지 결정

Isotropic (등방성) - 모든 방향으로 균등하게 산란

빛의 산란 3가지 - 레일리 산란 / 미 산란 / 기하 광학

레일리 산란 - 빛의 파장보다 부딪히는 입자의 크기가 작을 경우, 모든 방향으로 고르게 퍼지는 산란 (아령 모양)
미 산란 - 빛의 파장과 부딪히는 입자의 크기가 비슷할 경우, 전방(빛이 가던 방향)으로 집중 산란
기하 광학 - 빛의 파장보다 부딪히는 입자의 크기가 클 경우, 빛을 직선으로 가정

Henyey-Greenstein (HG) - 미 산란을 표현하기 위한 근사 공식
실제 안개/구름은 앞쪽으로 더 많이 산란

HG 공식

                      1 - g²
P(θ) = ─────────────
          4π(1 + g² - 2g·cosθ)^1.5

g = anisotropy 파라미터
θ = 빛 방향과 시선 방향 사이의 각도

g = 0 -> 등방성 (모든 방향 동일)
g > 0 -> 앞으로 산란 (태양 바라볼 때 밝음)
g < 0 -> 뒤로 산란

시각적 효과
g = 0.8 (Forward Scattering) - 일반적으로 그래픽스에서 사용하는 값
- 태양을 바라보면 -> 안개가 매우 밝게 빛남
- 태양을 등지면 -> 안개가 어둡게 보임


//-------------------------------------------------------------------------------------------------
// 6. Ray Marching Algorithm
//-------------------------------------------------------------------------------------------------

Step 1: 광선 설정

시작점:	카메라 위치
끝점:	픽셀의 월드 위치 (깊이 버퍼에서 복원)
방향:	정규화된 방향 벡터

[카메라] ────────→ [물체]
rayStart                          rayEnd

Step 2: 샘플 포인트 결정

totalDistance = length(rayEnd - rayStart)
stepSize = totalDistance / NUM_STEPS

	    stepSize
                ├──┤
[카메라] ──●──●──●──●──●──●──●──●──→ [물체]
                 0	1       2      3       4       5       6      7

Step 3: 각 샘플에서 계산

for each sample point:
1. 현재 위치의 안개 밀도 구하기
2. 현재 위치가 빛을 받는지 확인 (Shadow Map)
3. 투과율 업데이트 (Beer-Lambert)
4. In-scattering 누적
5. 다음 위치로 이동

Step 4: 최종 합성
최종 색상 = 배경 x 투과율 + 누적된 산란 빛
[ L = L_background x T + L_inscattering ]


//-------------------------------------------------------------------------------------------------
// 7. Pseudocode
//-------------------------------------------------------------------------------------------------

function RayMarchFog(rayStart, rayEnd):

      rayDir = normalize(rayEnd - rayStart)
      totalDist = length(rayEnd - rayStart)
      stepSize = totalDist / NUM_STEPS

      transmittance = 1.0          // 초기 투과율 (100%)
      inScattering = vec3(0, 0, 0) // 누적 산란 빛

      currentPos = rayStart

      for i = 0 to NUM_STEPS:

          // 1. 안개 밀도 샘플링
          density = SampleFogDensity(currentPos)

          // 2. 소멸 계수 계산
          extinction = density * extinctionCoeff

          // 3. 이 구간의 투과율 (Beer-Lambert)
          segmentTransmittance = exp(-extinction * stepSize)

          // 4. 빛이 이 위치에 도달하는지 확인
          lightVisibility = SampleShadowMap(currentPos)

          // 5. Phase Function 계산
          phase = HenyeyGreenstein(lightDir, -rayDir, g)

          // 6. In-scattering 계산
          //    = 빛의 세기 × 빛 도달 여부 × 밀도 × Phase × 현재까지의 투과율
          scattering = lightColor * lightVisibility * density * phase

          // 7. In-scattering 누적 (적분)
          //    투과율을 곱해서 카메라까지 도달하는 양만 누적
          inScattering += scattering * transmittance * stepSize

          // 8. 전체 투과율 업데이트
          transmittance *= segmentTransmittance

          // 9. Early exit (투과율이 거의 0이면 더 계산할 필요 없음)
          if transmittance < 0.01:
              break

          // 10. 다음 위치로 이동
          currentPos += rayDir * stepSize

      return (inScattering, transmittance)


//-------------------------------------------------------------------------------------------------
// 8. Shadow Map 통합
//-------------------------------------------------------------------------------------------------

왜 필요한가 ?

Shadow Map 없이:
- 안개 전체가 균일하게 밝음
- Light Shaft 불가능

Shadow Map 있으면:
- 그림자 영역의 안개는 어두움
- 빛이 통과하는 영역만 발긍ㅁ -> Light Shaft!

작동 방식

각 샘플 위치에서:
1. 월드 좌표 -> 라이트 공간 좌표로 변환
2. Shadow Map에서 깊이 샘플링
3. 현재 깊이와 비교 -> 빛을 받는지 판단

[태양]
     ＼
      ＼  빛이 통과
       ＼
        [안개]  ← 이 부분만 밝게
        /
      /  그림자
    /
[물체]


//-------------------------------------------------------------------------------------------------
// 9. 안개 밀도 결정
//-------------------------------------------------------------------------------------------------

방법 1: 균일 밀도
density = constantValue // ex: 0.02

방법 2: Height Fog (높이 기반)
density = baseDensity * exp(-heightFalloff * worldPos.y)
-> 낮은 곳에 안개가 많고, 높은 곳은 맑음

방법 3: 노이즈 기반
density = SampleNoiseTexture(worldPos * noiseScale)
-> 뭉게뭉게 자연스러운 안개

방법 4: 조합
density = heightFog * noise * globalDensity
