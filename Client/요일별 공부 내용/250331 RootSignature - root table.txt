Root Signature에서 root table 사용시
SetDescriptorHeaps & SetGraphicsRootDescriptorTable 사용 필수

Constant Buffer View (descriptor heap)를 만들어 Constant Buffer를 가리키게 만들어줌
Constant Buffer View를 Register에 제출하기 위해 또 다른 descriptor heap을 만들어줌 [즉시 실행됨 CopyDescriptors] - Device에서 작업
복사한 Descriptor Heap을 Register에 제출함 [나중에 실행됨 SetDescriptorHeaps & SetGraphicsRootDescriptorTable] - CommandList에서 작업

SetDescriptorHeaps -> 힙 자체를 어떤걸 활용할지 CommandList에 묶어주는 함수
SetGraphicsRootDescriptorTable -> 배열 중 몇번 째 것을 활용할지 골라주는 함수

SetDescriptorHeaps는 어마어마하게 느리기 때문에 남발하면 안됨.
한번 만들때 어마어마하게 크게 만들어서 다시 또 호출하게 하지 말아야함.
Command라인에 제출용으로 활용할거면 D3D12_DESCRIPTOR_HEAP_FLAG_SHADER_VISIBLE 로 설정해야함. 그래서 GPU 라인에 상주함.
즉, 두 descriptor heap중 cbv를 가리키는 것과 제출용으로 만드는 것의 설정은 다르게 두어야함.

예시로, 81개의 삼각형 그리려면 constantbuffer는 81 * 5개 필요함. = 405개
그럼 코드에서 constantbuffer init에서 256개가 아닌 최소 512개 할당 받아야함
