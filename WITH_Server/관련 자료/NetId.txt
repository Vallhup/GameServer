NetId 생명주기

Spawn
 1. NetId id = netIdRegistry.Allocate();
 2. netIdRegistry.BindEntity(id, entity);
 3. ecs.Add<NetIdComp>(entity, id);
 4. ecs.Add<ReplicatedTag>(entity);
 5. rep.NotifySpawn(entity);


Despawn
 1. NetId id = ecs.Get<NetIdComp>(entity).id;
 2. rep.NofityDespawn(entity);
 3. netIdRegistry.UnbindEntity(id);
 4. netIdRegistry.Free(id);
 5. Entity Destroy
